<p align="center">Радиальный конвертер файлов для macOS.<br>Зажми файл, нажми клавишу — брось в нужный сектор.</p>

## Установка

1. Скачайте `Morfus-<версия>.zip` из [последнего релиза](https://github.com/ehroz1/morfus-releases/releases/latest).
2. Распакуйте и перенесите **Morfus.app** в «Программы».
3. Первый запуск: правый щелчок по Morfus.app → «Открыть» → «Открыть».
   Если macOS всё равно не пускает: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»
   или в Терминале `xattr -dr com.apple.quarantine /Applications/Morfus.app`.

Работает на macOS 13 и новее, Apple Silicon и Intel.

Для видео, звука и PDF нужны бесплатные программы. Терминал не нужен: Morfus предложит поставить их
при первом запуске, или откройте «Настройки → Программы → Установить». Если на Mac нет Homebrew,
откроется его официальный установщик — нажмите «Продолжить» и введите пароль Mac, остальное Morfus сделает сам.

## Обновления

Morfus обновляется сам: раз в полчаса он проверяет этот репозиторий, и в меню значка появляется
**«Обновить Morfus до X»**. Один щелчок — новая версия скачивается, проверяется (SHA-256 и подпись) и
ставится с перезапуском. Можно ставить без щелчка: «Настройки → Справка → Обновления → Ставить сразу».
